## H1 — (a) バケツの主犯は固有名詞である

**登録時刻**: 実装計画（`~/.claude/plans/3-1-eager-reddy.md`）の承認時点。閾値は測定前に固定済み。

**対象**: (a) バケツ ＝ PapyGreek test トークンのうち、gold レンマが B3u の候補集合に含まれるが順位が5位以下のもの。

**測定器**:
- 主信号 — gold レンマの語頭が大文字か（NFD 分解後の基底文字で判定し、気息記号付き大文字を取りこぼさない）
- 交差確認 — dump の `postag`（AGDT 9文字、position 0 が品詞）。AGDT に固有名詞タグは無いので、大文字判定を**反証はできるが確証はできない**補助信号として扱う。

**判定規則**:
- 固有名詞比率 **> 50%** ⇒ 採択。残り 15.2pt の主犯はそこであり、対策はランキング改良ではなく**オノマスティコン追加**という別カテゴリの作業になる。
- **< 20%** ⇒ 棄却。
- 20–50% ⇒ 保留。H2 の結果と合わせて判断する。

**結果（2026-08-12、`results_propnoun_test.json`）**

| バケツ | n | 大文字 gold | 比率 |
|---|---:|---:|---:|
| hit@5 | 1,084 | 89 | 8.2% |
| **(a) 候補にあるが5位圏外** | **289** | **15** | **5.2%** |
| absent 候補集合に無い | 115 | 44 | **38.3%** |
| test 全体 | 1,488 | 148 | 9.9% |

**5.2% < 20% ⇒ H1 棄却。** (a) バケツの固有名詞比率は全体基準率 9.9% を**下回る**。固有名詞は順位付けが難しいのではなく、むしろ易しい。

**DDbDP 上位300レンマのうち56語が、文学ギリシャ語 1,439万トークンに一度も現れない。** その中に `Ἁθύρ`（エジプトの月名）が含まれる——H1 の (a) バケツで実際に失敗していた語である。二つの所見が繋がる。

**この証拠の限界を明示する**: これはユニグラム分布の差であって、トライグラム文脈が順位付けを助けるかどうかとは別の問いである。語彙が違うことは、文脈が効くことを含意しない。H2 の判定はあくまで dev recall@5 で行う。

**基準**: R0 = dev recall@5 **74.55%**（`dump_b3u_feat.jsonl`、`--split dev`、672トークン / 88文書）。実行時に `run(contexts(rows,"gold"), 0.0)` で再現して照合する。

**主要評価項目**: context mode **`dilemma`**（実運用可能な方）での dev recall@5。`gold` は天井として併記するが判断には使わない。

**判定規則**:
- **採択** — dev recall@5 ≥ **80.55%**（R0 + 6.0pt）かつ対比較ブートストラップ 95% 区間がゼロを除外。このときのみ PapyGreek test で一度だけ確認測定する。
- **確認されたが不十分** — 利得が [+3.1pt, +6.0pt) で区間がゼロを除外。記録するが採択しない。test に触れない。
- **棄却**（「文脈信号は打ち止め」）— それ以外。

**多重性**: 4コーパス × 4重み × 2文脈 = 32セル＋基準を一つの基準に対して比べる。報告する見出しは**セル横断の最大点推定**であり、相関のある32検定に対する選択で上方バイアスがかかる。+6.0pt という閾値を既知の +3.1pt より遥か上に置いたのはこのバイアスを吸収するためである。α補正は行わず、最大セル以外に主張を持たせない。全セルを `results_lm_dev_{tag}.json` に書き出して選択過程を検証可能にする。

**ドメイン対量の統制**: GLAUx-full を DDbDP と同トークン数に切り下げた条件（C_B′）を必ず含める。これが無いと「in-domain が効いた」と「データが増えた」を分離できない。C_C ≥ C_B′（同トークン数）ならドメインに帰属、C_B > C_C なら量に帰属。**帰属規則を測定前に固定する。**

**分割の感度**: 最良重みにおいて `--group ∈ {1, 3, 999}` で再実行。dev recall@5 の振れ幅が 0.5pt 未満なら分割は無関係と宣言し `group=3` を凍結する。レンマ化のやり直しは不要。

**リーク除外の感度**: TM 単位除外と series+volume 単位除外の両方でコーパスを作る。dev@5 の差が **1.5pt を超えたら series+volume 版を報告値とする。**（LM コーパスは保守側の series+volume 除外のみで構築した。）

### なぜ効かなかったか — 被覆率による機構の特定

dev の LM が gold・上位20候補・文脈語をどれだけ語彙に持つか：

| コーパス | gold 被覆 | **候補@20 被覆** | 文脈語 被覆 | 利得 |
|---|---:|---:|---:|---:|
| GLAUx-30 | 78.3% | **41.3%** | 72.8% | +3.1 |
| GLAUx-matched | 81.0% | **52.5%** | 77.5% | +3.1 |
| DDbDP | 88.9% | **49.3%** | **93.3%** | +3.4 |
| GLAUx-full | 84.8% | **66.5%** | 79.4% | +3.6 |
| GLAUx-full + DDbDP | 92.4% | **75.0%** | 93.9% | +4.2 |

**DDbDP は文脈語被覆を 77.5% → 93.3%（+15.8pt）、gold 被覆を 81.0% → 88.9%（+7.9pt）に引き上げて、recall を +0.3pt しか動かさない。**利得が追随しているのは**候補被覆**のほうである（41.3→52.5→49.3→66.5→75.0 と +3.1→+3.1→+3.4→+3.6→+4.2）。

機構は明快である。**トライグラムは自分が見たことのある候補しか並べ替えられない。**語彙に無い候補はバックオフの床値を受け取り、他の未知候補と区別がつかなくなる。in-domain データが劇的に改善するのは**文脈を知っていること**だが、文脈語は καί・ὁ・τοῦ のような高頻度機能語で、**どのコーパスにも既にある**。改善しないのは**候補を知っていること**で、候補は稀語である。

したがって ἀρτάβη が 13,668倍という語彙の差は、順位付けにはほとんど転換されない。**「効いているのは文学とパピルスで共有される高頻度の連鎖である」という読みが、統制付きで確認された。**

律速は文書のドメインではなく**辞書側の稀語被覆**である。これは LM を大きくしても解けない——C_D が最良なのは、gold 被覆と候補被覆の両方が高い唯一の条件だからで、ドメインが効いたからではない。

**登録**: 測定前。

**評価項目**: `ddb_splits.json` の **dev** 分割、recall@5 lenient（`norm_lenient`）、TM でクラスタリングしたブートストラップ。

**反証可能な予測（測定前に固定）**: PapyGreek B0 の `link_key_lenient = 1800/2160 = 83.3%` を橋にすると、既知の dev レンマ到達率 74.55% は **N_dev ∈ [80%, 95%]** を含意する。この帯から外れたら抽出器か form ターゲット生成器が誤っているので、どちらのベンチマークも報告する前に原因を特定する。

**推定量とその仮定**: `L̂ = N × 0.833`。**独立性を仮定**している——「B3u が正しい reg 形を top-5 に入れる」と「辞書がその reg 形を gold レンマに繋ぐ」が独立だという仮定。これは**偽であり、バイアスの符号は不明**である。両方向とも既に手元に証拠がある：

- **楽観側（積が過大）** — どちらの失敗も稀少性と相関する。H1 の副次的発見（候補集合に無いバケツの固有名詞比率が基準率の4倍）がその証拠。正規化しにくい形は辞書にも無い確率が高いので、真の同時確率は積より小さい。
- **悲観側（積が過小）** — レンマ経路は編者の reg 形を通る必要が無い。`rlb_analyze.py` が明記している通り、union 生成器はレンマのどの形からでも到達する。したがって L は N × 0.833 を超えうる。

**使用制限**: L̂ は桁の健全性検査にのみ使い、L を測る代わりには決してしない。実測値と含意値が **10pt** を超えて食い違えば、二つのベンチマークが想定通りのものを測っていない。

**追加の仮定（補正しない、明記だけする）**: 0.833 は DDbDP の reg 形が PapyGreek の variant_ortho の reg 形と同じ分布に従うことを仮定している。従わない（PapyGreek は36系列、UPZ / BGU / O.Claud / P.Cair.Zen に偏る。DDbDP は全体）。

**新ベンチマークの test 分割は封印**する。第3次で必要とする事前登録済み比較は存在しない。

### パイロット（n=19、2026-08-12）で判明した2点

n=19 は判定には全く足りない。以下は数値の主張ではなく**測定器の欠陥**の所見である。

**(1) form ターゲットでは strict 指標が意味を持たない。** パイロットで strict@5 26.3% 対 lenient@5 73.7% と47ポイント開いた（レンマ課題では約2ポイント）。原因はギリシャ語のアクセントで、鋭アクセント・重アクセントの交替は**位置によるもので語彙的ではない**。編者は文中の位置に応じた `Μεσορὴ`（重）を書き、辞書は引用形の `Μεσορή`（鋭）を持つ。`ἀναφάλαντός`／`ἀναφάλαντος`（前接辞のアクセント）、`δανειστήν`／`δανειστὴν` も同じ。strict は「編者の文脈依存アクセントを当てられたか」を測っており、それは課題ではない。**lenient を主要指標とする事前登録は正しく、strict は弱い変種としてではなく「適用外」として報告する。**

**(2) DDbDP の `<choice><reg>` は正書法の正規化より広い。** パイロットの失敗例に `οἱμοι → ὁμοίως`、`ζηκωτάτη → ζυγοστάτης`（いずれも本文の校訂＝別語への置換）、`Μηνᾶς → Μηνᾶ`（格変化）が含まれる。PapyGreek は `variant_ortho` と `variant_lex` を明示的に分けている（`lemma_orig == lemma_gold` が条件）が、**DDbDP はこの区別を持たない**。分けずに報告すれば、新ベンチマークは旧ベンチマークより難しい別の課題を測っていることになり、二つの数字は比較できない。事前登録した [80%, 95%] の帯はまさにこれを検出するために置いたものであり、機能した。

**対応（事前登録の追補）**: `rlb_ddb_strata.py` で両側をレンマ化し、`lemma_orig == lemma_reg` なら `ortho`、異なれば `lex`、どちらかが未解決なら `unknown` と分類する。**H3 の主要評価項目を `ortho` 層に限定する**——PapyGreek の `variant_ortho` と定義を揃えるため。

この再構成の限界を明示する：PapyGreek は**人手の注釈**で層を決めており、こちらは**道具**で代用している。Dilemma が解決できないペアは推測せず `unknown` とし、その比率をこの層に由来する全ての数値の隣に併記する。`lex` 層と `unknown` 層の数値も捨てずに報告する。

### 層化の結果（121,116ペア）

| 層 | 件数 | 割合 |
|---|---:|---:|
| lex（レンマが変わる＝本文の校訂） | 49,028 | **40.5%** |
| **ortho（レンマが同じ）** | **39,562** | **32.7%** |
| unknown（片側が未解決） | 32,526 | 26.9% |

**DDbDP の `<choice><reg>` の 40.5% はレンマが変わる**。パイロットの所見が実規模で確認された。

### H3 の結果 — 予測は falsify された（dev, ortho, n=968, 500文書）

| 指標 | 値 |
|---|---:|
| **recall@5（主要）** | **57.4%** |
| recall@1 | 18.9% |
| recall@20 | 73.3% |
| recall@inf | 85.2% |
| 候補ゼロ | 0.2% |
| \|C\| 中央値 / p90 | 256 / 839 |

**57.4% は事前登録した [80%, 95%] の帯を大きく外れる。事前登録の規則により、原因を特定するまで報告しない。**

### 原因の特定 — これはバグではなく課題の性質である

生成器は正常である（recall@inf 85.2%、候補ゼロ 0.2%）。壊れているのは順位付けで、recall@1 が 18.9%（レンマ課題では 52.8%）。失敗例を読むと原因は一つに収束する：

| papyrus | reg | 変化 |
|---|---|---|
| σου | σοι | 属格 → 与格 |
| τοῦ | τῷ | 属格 → 与格 |
| γενομενους | γενόμενοι | 対格複 → 主格複 |
| Ἰσιδώρου | Ἰσιδώρῳ | 属格 → 与格 |
| ἐχον | ἔσχον | 現在 → アオリスト |
| ἔβαλα | ἔβαλον | コイネー第1アオリスト語尾 → 古典第2アオリスト |
| αὐτὰ | αὐτὰς | 中性複 → 女性対格複 |

**これらは屈折の訂正であって正書法の訂正ではない。そして papyrus 側の形は、それ自体が完全に正しいギリシャ語である。**したがって cost 0.0 の完全一致が勝ち、正解（別の格の形）ははるか下に沈む。

**`lemma_orig == lemma_reg` という層の定義は、屈折の変化を除外しない。** σου と σοι はレンマが同じ（σύ）、τοῦ と τῷ も同じ（ὁ）。定義が意図どおり働いていないのではなく、**定義が捉えられない区別がある**。

定量化：

| dev ortho 層 | 件数 | 割合 | recall@5 |
|---|---:|---:|---:|
| **papyrus 形がそれ自体辞書にある語** | 454 | **46.9%** | **45.8%** |
| papyrus 形が辞書に無い語 | 514 | 53.1% | 67.7% |

これは第1次 §4.1 の real-word error（πεδίων ／ παιδίων）と同じ機構が、**新ベンチマークでは半数を占めて支配的になっている**ということである。

### 帰結 — 第二ベンチマークは lemma ベンチマークの代替にならない

**form→form は form→lemma より構造的に難しい。**前者は屈折まで当てる必要があり、後者は免除される（σου も σοι もレンマは σύ なので、レンマ課題では格の誤りが誤りにならない）。

したがって：

1. **`L̂ = N × 0.833` の橋は無効である。** 独立性の破れどころではなく、N は L が免除されている一群の訂正によって押し下げられている。この推定量は撤回する。
2. **test 枯渇問題は、この形では解決されない。** 121,116ペアは orig→reg 正規化という**別の課題**の評価集合であって、レンマ到達の評価集合ではない。DDbDP には人手のレンマ注釈が無いので、レンマ課題版を作るには注釈が要る（Dilemma で代用すると、層の定義と評価対象が同じ道具になり循環する）。
3. **ただしベンチマーク自体は無価値ではない。** 正規化は編者が実際に行う作業そのものであり、CC BY で 121,116 件、26,701 文書、時代・地域・文書種で層化可能という資源は他に無い。**別の課題の評価集合として**報告するのが正しい。

事前登録した帯は2度機能した（パイロットで測定器の欠陥を、本測定で課題の非等価性を検出した）。**これが帯を置いた理由である。**

## H4 — 探索区画は必要か（記述的、推論的主張は一つだけ）

**登録**: 測定前。

**指標**: dev の recall@5 ヒットのうち、gold が**探索区画経由でのみ**到達したもの（`rule_reachable` が偽）の割合。

**判定**:
- **< 10%** ⇒ 15交替がほぼ全ての仕事をしており、素の編集距離は安全網にすぎない。
- **> 30%** ⇒ 名前の付いたルールが凍結リストから実質的に欠けている。

**dev のみ。** `ALTERNATIONS` は凍結したまま。成果物は `alternations_undescribed.json`（16番目のルール候補の文書化されたリスト）であって、コード変更ではない。

**結果（2026-08-12、`results_zones_dev.json`）**

区画判定はコストだけからは読めない。`_from_keys` が最小タプルを保持するため、ルール（3.0）と blind Lev-1（1.5）の両方で到達した候補は 1.5 で記録され探索区画に見える。**コストのみの素朴な判定は候補スロット 527,305 のうち 97,527 を誤分類する**（コスト1.5 の 87.9%）。索引を作り直さず O(1) の文字列判定で復元できる：

```
rules    collapse(src_key) ∈ b3_variants(word)
rules+1  Lev(collapse(src_key), b3_key(word)) ≤ 1
```

凍結 dump に対して検証済み——コスト 0.0 / 1.0 / 3.0 に記録された候補はすべてこの判定で真になる（偽陰性なし）。

| k | recall@k | confident 経由 | explore 経由 | explore のヒット内比率 |
|---:|---:|---:|---:|---:|
| 5 | 74.6% | 480 (95.8%) | 21 | **4.2% [2.3, 6.8]** |
| 20 | 84.4% | 541 (95.4%) | 26 | 4.6% [2.6, 7.1] |
| 50 | 89.7% | 572 (94.9%) | 31 | 5.1% [3.4, 7.5] |

**4.2% < 10% ⇒ 15交替がほぼ全ての仕事をしている。素の編集距離は安全網である。** 区間上端 6.8% も閾値を下回るので判定は堅い。

**§1.1 の読み方の精密化（事後、探索的）**: explore 比率は k を 5→20→50 と広げても 4.2%→4.6%→5.1% とほぼ平坦である。したがって §1.1 の「B3ur は @20 で B2u に負ける（−2.4\*）」は、**素の編集距離だけが到達できる gold が裾に居るからではない**。B3u の内部では、どの k でも gold の約95%はルールで到達可能である。@20 の符号反転は到達可能性ではなく**リストの構成と順序**の問題である。これは §1.1 の系間比較とは別の分解なので矛盾はしないが、「15交替は頭を取り、素の編集距離は裾を取る」という要約は不正確で、正しくは「15交替がほぼ全てを取り、素の編集距離は少数を安定して拾う」である。

**未記述交替の候補（dev, k=20, `alternations_undescribed.json`）**: 探索区画のヒット26件、12グループ。実質的な候補は2つ：

- **γ 脱落（母音間）** — `υἱαίνομεν → ὑγιαίνω`、`υἱαίνῃς → ὑγιαίνω`。ὑγι- の γ が消える実在の音韻変化で、15交替に無い。**16番目のルールの最有力候補。**
- **-οσαν / -ον（3複未完了）** — `ἐλαμβανοσαν`、`ἐλαμβανεσαν → λαμβάνω`。コイネーの動詞語尾で、正書法ではなく形態論。別カテゴリとして扱うべきもの。

残りは `categorize.label` の分類が緩いことによる見かけ（`Ἡραΐσκου → Ἡραΐσκος` は屈折であって交替ではない）か、上の `clean.py` 欠陥の産物である。
